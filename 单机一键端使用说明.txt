========================================
  WoW 3.3.5a 单机一键端 · 使用说明
========================================

【你的客户端】
  路径: E:\wow\World of Warcraft
  版本: 3.3.5a (12340) 国服
  realmlist 已改为: 127.0.0.1  （连本机）

【服务端放哪里】
  请把下载的一键端 解压到:
    E:\wow\server\
  解压后目录里通常能看到类似文件/文件夹:
    - authserver.exe / worldserver.exe  （或 登录服 / 世界服）
    - mysql / database / 数据库
    - 启动.bat / 一键启动.bat / start.bat
    - 使用说明 / readme

----------------------------------------
一、去哪里找一键端
----------------------------------------
搜索关键词（任选）:
  · 3.3.5a 一键端
  · 巫妖王 单机 一键端
  · WotLK 3.3.5 单机服

注意:
  1. 必须是 3.3.5a，不要下错版本（如 2.4.3 / 4.3.4）
  2. 优先选「完整包」（自带数据库），不要只下客户端
  3. 文件很大（几 GB～十几 GB），请下到 E 盘
  4. 杀毒软件可能误报服务端 exe，可对 E:\wow\server 加信任

----------------------------------------
二、安装步骤（通用）
----------------------------------------
1. 解压到 E:\wow\server\
2. 先看包内的「使用说明 / readme / 必读」
3. 若有「安装数据库.bat」或「初始化」，先运行一次
4. 用管理员身份运行「一键启动」或分别启动:
     数据库 → 登录服(auth) → 世界服(world)
5. 等世界服窗口出现类似:
     World initialized / 世界服务器已启动
     再开客户端

----------------------------------------
三、创建账号（常见几种）
----------------------------------------
方式 A - 服务端窗口命令（最常见）:
  account create 你的账号 你的密码
  account set gmlevel 你的账号 3 -1

方式 B - 自带网页注册（浏览器打开说明里写的地址）

方式 C - 自带「创建账号.bat」小工具

----------------------------------------
四、进游戏
----------------------------------------
1. 确认服务端都已启动
2. 运行: E:\wow\World of Warcraft\Wow.exe
3. 用刚创建的账号密码登录
4. 选服务器（一般是本机 / 127.0.0.1）→ 建号开玩

----------------------------------------
五、常见问题
----------------------------------------
【连不上 / 无法连接】
  · 是否先启动了登录服+世界服？
  · realmlist.wtf 是否为: set realmlist 127.0.0.1
  · 防火墙是否拦截了 auth/world（可临时关防火墙试）

【版本不匹配 / 客户端版本错误】
  · 一键端必须是 3.3.5a，与客户端 12340 一致

【闪退 / 黑屏】
  · 用兼容模式 Win7，或以管理员运行 Wow.exe
  · 显卡驱动更新一下

【卡顿 / 内存不足】
  · 你机器约 8GB 内存，只开服务端+WoW，关掉浏览器多标签

【想改掉落 / 刷装备】
  · 进游戏后 .gm on
  · 常用: .additem 物品ID 数量  /  .levelup  /  .tele 地点
  · 具体命令看你一键端自带的 GM 命令表
